# Third-Party Licenses

This document lists the third-party assets and their licenses used in Soul Engine.

## Fonts

### Roboto Font Family

**Location:** `resources/fonts/Roboto/`

**Copyright:** Copyright 2011 The Roboto Project Authors (https://github.com/googlefonts/roboto-classic)

**License:** SIL Open Font License, Version 1.1 (OFL-1.1)

The Roboto font family is used for UI text rendering. The complete license text is included in `resources/fonts/Roboto/OFL.txt`.

The OFL allows:
- Free use, modification, and redistribution
- Bundling with software
- Commercial use

Requirements:
- Include copyright notice and license with distribution
- Cannot sell the fonts by themselves
- Derivative works must use the same license

For the full license text, see: https://openfontlicense.org
